# VisionForge Image Studio

A professional image generation web app with a polished studio interface, Puter.js browser image generation, prompt controls, downloads, and local history.

## Run

```bash
npm run dev
```

Open `http://localhost:3000`.

## Configuration

Create a `.env` file:

```bash
IMAGE_PROVIDER=puter
PORT=3000
```

Then restart the server.

## Notes

This project uses Puter.js in the browser for image generation, so no separate paid image API setup is required.
